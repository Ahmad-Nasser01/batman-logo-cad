# Onshape Batman Logo Project

This repository contains the 3D CAD design of a Batman logo created using Onshape and exported as an STL file for the mechanical design task.

## Task Details:
- Designed a custom Batman logo with precise dimensions.
- Performed an Extrude operation with a height of 2 mm.
- Exported the model in STL format.

## Uploaded Files:
- `Batman_Logo.stl`: The 3D printable STL file of the logo.
